# Doit — اپ مدیریت کارهای روزانه

یک پروژهٔ اندروید دوزبانه (فارسی/English) با Kotlin و Jetpack Compose.

## امکانات نسخهٔ اول

- داشبورد «امروز» با کارهای روزانه و میزان پیشرفت
- ایجاد کار جدید با زمان و دسته‌بندی
- تیک‌زدن کارهای انجام‌شده
- مراحل فرعیِ قابل باز و بسته‌شدن برای هر کار
- صفحهٔ برنامهٔ هفتگی و صفحهٔ «نبض» برای مرور پیشرفت
- تغییر لحظه‌ای زبان فارسی/English از بالای صفحه
- درخواست اجازهٔ موقعیت برای آماده‌سازی آب‌وهوای خودکار
- کارت آب‌وهوا با طراحی اختصاصی؛ در این نمونه دادهٔ نمایشی تهران دارد

## اجرا در Android Studio

1. پوشهٔ `Doit` را در Android Studio (نسخهٔ جدید) باز کنید.
2. اجازه دهید Gradle همگام‌سازی شود و Android SDK 35 نصب باشد.
3. یک شبیه‌ساز با API 26 یا بالاتر بسازید، یا گوشی را با USB debugging وصل کنید.
4. دکمهٔ Run را اجرا کنید.

## نکتهٔ آب‌وهوا

مجوز موقعیت هم‌اکنون از کاربر درخواست می‌شود. برای نمایش آب‌وهوای زنده، باید در مرحلهٔ بعد یک سرویس آب‌وهوا (برای نمونه Open-Meteo) به پروژه متصل شود. این کار بدون کلید API هم قابل انجام است و موقعیت فقط پس از موافقت کاربر استفاده خواهد شد.

## جهت طراحی

رنگ اصلیِ سرمه‌ای، آبی آسمانی، نعنایی و مرجانی است. نقطهٔ متمایز طراحی، کارت «هوای امروز» با فضای شبانه و کارت‌های کم‌تزئین و نرم برای حفظ تمرکز روی کارهاست.
